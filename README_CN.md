# 极速全文搜索

## 优势
###  1. 无索引不占空间

目前比较流行的全文搜索软件有Recoll和AnyTXT，它们速度非常快，但是以建立索引为前提的，索引体积几个G起步，且会不断增长。

### 2. 结果齐全
经对比测试，虽然AnyTXT速度更快，但搜索结果比本软件少，不齐全。

### 3. 速度快

虽然与Recoll和AnyTXT相比较慢，但对全盘搜索并不慢，特别是指定文件类型情况下，速度极快。因为它会调用全部CPU资源多线程、满负荷、并行搜索。

### 4. 搜索范围广
可直接搜索压缩文件内部的内容，Docx、PDF以及所有文本类文件，如：html、txt、电子书等。

### 4. 支持高级搜索
可多关键字搜索，支持正则表达式搜索。利用文件类型通配符，和全文关键字可以组合出各种灵活的搜索方法。界面简单但功能灵活。

### 5. 使用方便
所有功能均在界面上，有不懂的地方，鼠标悬浮在需要了解的地方，会弹出使用说明。
